## 📊 AI Financial Assistant
<img width="1447" height="925" alt="image" src="https://github.com/user-attachments/assets/eca06d34-33de-44bf-b519-63ff2bc3b362" />


Uma ferramenta simples de controle financeiro que transforma dados de transações em gráficos intuitivos e análises inteligentes com IA.

### Funcionalidades
- Importação de dados financeiros via CSV padronizado.
- Visualização de gastos mensais e anuais.
- Gráficos interativos e de fácil compreensão.
- Análises e insights financeiros gerados por IA.

### Como utilizar

1. Baixe o arquivo HTML da aplicação disponível neste repositório.
2. Abra o arquivo HTML no navegador (não é necessário instalar nenhum programa).
3. Utilize a base de dados de exemplo ou importe seus próprios dados financeiros em .xlsx.
4. Se preferir, insira os gastos manualmente na tabela.
5. Visualize seus resultados em gráficos mensais e anuais.

### Base de dados

Para testar a aplicação, utilize a base de dados de exemplo:

[**Baixar base de dados (.xlsx)**](https://github.com/jpgoot22/Portifolio/blob/main/Web/AI%20Financial%20Assistant.xlsx)

### Tecnologias
- HTML
- CSS
- JavaScript
- Inteligência Artificial (utilizada no desenvolvimento do código).

### Objetivo
Aplicar tecnologia e IA para simplificar a análise de dados financeiros e facilitar a tomada de decisões.

## ✈️🌍 Interactive Travel Planner

- HTML
- CSS
- JavaScript
- Local Storage
- Inteligência Artificial (utilizada no desenvolvimento do código).

### Objetivo
Organizar informações de viagem em uma aplicação interativa, prática e de fácil edição.

## ⏳ Eisenhower Matrix & Weekly Planner

<img width="1532" height="765" alt="image" src="https://github.com/user-attachments/assets/1f0cdde2-4872-457f-8ed8-a3cb7d84fdd2" />


Aplicação interativa de gestão de tarefas que combina a Matriz de Eisenhower com o planejamento diário e semanal.

### Funcionalidades
- Priorização de tarefas com base na urgência e importância.
- Planejamento diário e semanal de tarefas.
- Organização de tarefas por meio de arrastar e soltar (drag-and-drop).
- Criação, edição, exclusão e inserção de múltiplas tarefas.
- Salvamento automático dos dados e detecção de tarefas duplicadas.
- Temas claro e escuro.

### Tecnologias
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Local Storage
- Inteligência Artificial (utilizada como auxílio no desenvolvimento).

### Objetivo
Combinar a priorização de tarefas com o planejamento da execução em uma única ferramenta de produtividade.
